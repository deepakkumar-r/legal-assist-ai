# Accessibility

LexClarity targets WCAG 2.1 AA. It uses semantic header/nav/main/section/footer landmarks, ordered headings, native controls, labeled fields, tab semantics, and `aria-live` status/error regions. Risk never relies on color: every badge includes an icon and text. Focus rings meet contrast needs, body text uses high-contrast ink, touch targets are comfortably sized, layouts reflow below 900 px and 600 px, and reduced-motion preferences disable animation.

Manual keyboard check: Tab reaches language, navigation, workspace tabs, upload, fields, style toggle, submit, result disclosures, Q&A, export, and handoff in visual order. Enter/Space activates each control. Browser zoom at 200% preserves the one-column workflow without horizontal scrolling.

The generated interface uses no meaningful raster imagery; decorative document art is `aria-hidden`.
